# ykw815.github.io

A minimal personal site listing project links.

## Local preview

Open `index.html` in a browser, or run a simple server:

```bash
python3 -m http.server
```

Then visit http://localhost:8000

## Deploy to GitHub Pages

1. Push `index.html` and `styles.css` to the `main` branch at the repository root.
2. On GitHub: **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**
4. Branch: **`main`** / **`/ (root)`**
5. The site will be available at https://ykw815.github.io/

No build step required.
